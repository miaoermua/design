技术来源缩写：

- **协议** = Mix Space 官方 API v2 已定义的接口或字段；
- **参考** = Shiro / kami / mx-starter 的产品完成度参考（不复制实现）；
- **依赖** = 由 `package.json` 里的第三方库提供能力；
- **自主** = Folio 自己设计的实现，协议中没有对应概念。
